# AI Agent Systems V3.0 — Project Copilot

## Short description

A local project copilot that searches your notes, answers with source references, and turns explicit TODOs into tasks you control.

## Project description

AI Agent Systems V3.0 is a local workspace for makers who lose project decisions, test plans, and next steps across scattered files. Import notes, READMEs, specifications, or code, then ask questions and inspect the exact source lines behind each result. A persistent task board and exportable reports keep the findings useful after the conversation ends. Evidence mode works immediately without API keys; optional Ollama and OpenRouter integrations add AI synthesis with source-reference checks and visible fallbacks. V3 replaces the earlier disconnected demonstrations with one usable application built around project memory, traceable evidence, and human-controlled actions.

## What's new relative to the earlier repository

- A working browser interface and installable CLI.
- SQLite-backed projects, imports, search, reports, and tasks.
- Real model HTTP integrations when configured, rather than labels implying execution.
- Source inspection, reference validation, offline fallbacks, and report exports.
- Automated workflow and failure-case checks, with the remaining limits documented.
